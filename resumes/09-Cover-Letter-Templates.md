# Cover Letter Templates

> Append a new section here for each role you apply to. Managed by `../skills/tailored-resume-builder.md`. Voice rules: first-person, contractions, personal asides, varied openers/closers. See `../RESUME-FORMAT-RULES.md` for the full checklist.

---

## Template Structure (~350-400 words)

```
Dear [Hiring Manager / Recruiter Name],

[Opening: 1-2 sentences. Name the role. Say why it caught your eye in one specific line. VARY this opener — don't start every letter with "I'm applying for..."]

[Transition sentence into evidence]

- **[JD requirement 1].** [Your proof — what you shipped, the metric, the outcome.]
- **[JD requirement 2].** [Your proof.]
- **[JD requirement 3].** [Your proof.]
- **[JD requirement 4].** [Your proof.]

[Optional: Honest disclosures section if there are gaps]
> Honest note: [Name the gap]. [What you have instead]. [Your path forward / commitment to ramp.]

[Closer: 1-2 sentences. Offer to share work samples or discuss further. VARY this closer.]

[Sign-off — cycle through: Thanks, / Talk soon, / Cheers, / Looking forward, / Best, — NEVER default to "Best regards" every time]

[Your Name]
```
